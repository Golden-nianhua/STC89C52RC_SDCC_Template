# 实验源码

每套实验代码只使用一个源码文件，并直接放在对应实验目录下：

- `Lab01` 至 `Lab04`：使用 SDAS8051 汇编，扩展名为 `.asm`。
- `Lab05` 至 `Lab08`：使用 C，扩展名为 `.c`。

文件名使用 `序号_功能` 格式，例如 `02_flow_led.asm` 或 `03_uart.c`。
CMake 会自动创建 `lab01_02_flow_led`、`lab05_03_uart` 这样的固件目标，
不需要为新增子实验修改构建脚本。

汇编文件必须自行定义复位入口和所需中断向量，并使用 SDAS8051 语法。
C 文件可以包含 `stc89.h`，该头文件同时兼容 SDCC 和 Keil C51。
